# STM32F070 FreeRTOS Industrial Control Demo

Final project for a university "Informática y Comunicaciones Industriales" course: an STM32F070RB running FreeRTOS controls several actuators/sensors and exchanges data with a Windows desktop GUI over UART, with two boards able to share live status over CAN bus.

The project has two parts, kept as two folders in this repo:

- **`firmware/`** — STM32CubeIDE project (C, FreeRTOS via CMSIS-OS2) that runs on the STM32F070RB (Nucleo board).
- **`gui/`** — Visual Studio C# WinForms application used to command the board and visualize its status from a PC.

## Features

- **Stepper motor** control: direction and speed (open-loop, phase sequencing).
- **Servo motor** control in three modes: driven by a potentiometer (ADC), driven by a position command from the GUI, and an automatic open/close sequence with configurable speed and dwell time.
- **Temperature sensing** via ADC, streamed periodically to the GUI.
- **SPI OLED display** (SSD1306): shows live servo/temperature/motor status, or one of several bitmap screens (skull, Garfield, ST logo, EPS logo), selected from the GUI.
- **CAN bus link** (via two MCP2515 SPI CAN controllers): once enabled, two boards running this firmware can exchange live status (temperature, servo position, motor speed/direction) with each other.
- Everything is implemented as independent FreeRTOS tasks synchronized with queues, semaphores and event flags — UART RX/TX, ADC sampling, stepper control, servo control, OLED refresh, and CAN handling all run concurrently.
- **PC GUI**: opens/closes the serial port, sends commands, and displays incoming values on gauges/LEDs built with the open-source [LBIndustrialCtrls](https://github.com/ztony478/LBIndustrialCtrls) WinForms control library.

## Communication protocol

The board and the GUI talk over UART (38400 baud) using fixed 4-byte frames: `[CMD] [DATO_0] [DATO_1] [EOF]`, with `EOF = 0xE0`.

### PC → board (commands)

| Byte | Command | Meaning |
|---|---|---|
| `0x41` ('A') | Auto servo sequence | `DATO_0` = dwell time (s), `DATO_1` = speed |
| `0x43` ('C') | Stop | Stops motor, servo, ADC and transmission tasks |
| `0x44` ('D') | Stepper: clockwise | Resumes stepper + related tasks |
| `0x49` ('I') | Stepper: counter-clockwise | Resumes stepper + related tasks |
| `0x4D` ('M') | Stepper speed | `DATO_0` = speed (RPM-like value), via GUI knob |
| `0x50` ('P') | Servo: potentiometer mode | Servo position follows the ADC/potentiometer |
| `0x52` ('R') | Enable CAN monitoring | `DATO_0` selects role: board A / board B / both |
| `0x53` ('S') | Servo: position command | `DATO_0` = target position (degrees) |
| `0x54` ('T') | Set temperature report period | `DATO_0`,`DATO_1` = period (ms), big-endian |
| `0x58` ('X') | OLED: data screen | Shows live servo/temp/motor readout |
| `0x60` | Resume all tasks | |
| `0x61`–`0x64` | OLED: bitmap screens | Skull / Garfield / ST logo / EPS logo |

### Board → PC (telemetry)

| Byte | Meaning |
|---|---|
| `0x20` | Servo position |
| `0x21` | Remote board's servo position (via CAN) |
| `0x30` | Local temperature (integer + decimal byte) |
| `0x31` | Remote board's temperature (via CAN) |
| `0x40` | Stepper speed + direction |
| `0x41` | Remote board's stepper speed + direction (via CAN) |

## Building

**Firmware (`firmware/`)**
1. Install [STM32CubeIDE](https://www.st.com/en/development-tools/stm32cubeide.html).
2. Open/import the project and build for the STM32F070RB (Nucleo-F070RB).
3. Wiring: stepper driver on `PC0-PC3`, servo on `TIM14_CH1` (PWM), potentiometer + on-board temperature sensor on `ADC1`, SSD1306 OLED on `I2C1`, two MCP2515 CAN modules on `SPI1` (chip-selects on separate GPIOs), status LED on `PA5`, user button on `PC13`.

**GUI (`gui/`)**
1. Open `ProyectoFinal_ICI.sln` in Visual Studio (.NET Framework 4.7.2). The project references `libs/LBIndustrialCtrls.dll`, included in this repo, so no extra setup is needed.
2. Build and run.
3. Set the correct COM port in the app and click "Abrir" to connect.
